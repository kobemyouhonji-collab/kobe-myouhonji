# 神戸・妙本寺 無料ホームページ

このフォルダの `index.html` だけで動作する、無料運用向けの静的ホームページです。

## 費用
- サイト制作：0円（このファイル）
- GitHub Pages 公開：0円
- SSL (https)：0円
- 外部ライブラリ：不使用
- 有料フォント：不使用
- 写真素材：不使用
- 独自ドメイン：使用しなければ0円

## 公開の最短手順（GitHub Pages）
1. GitHubの無料アカウントを作る
2. 新しいリポジトリを作成
3. `index.html` をアップロード
4. Settings → Pages → Deploy from a branch
5. `main` / `(root)` を選び保存
6. 数分後に無料URLで公開
