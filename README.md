- 「本堂」と誤記していた写真を、確認済みの名称「御宝蔵」に修正
- トップページの予定を2026年10月へ更新
- 青年部・少年部合同部会を「毎月、御講日の午前11時30分（御講前）」に統一
- 意味の分かりにくい大きな装飾用かぎかっこを削除
- `.nojekyll`、`robots.txt`、`favicon.svg`、`site.webmanifest` を同梱
